📦 **官方插件页：https://plugins.jetbrains.com/plugin/32115-stocklite**（IDE 内 `Settings → Plugins → Marketplace` 搜索 "StockLite" 即可安装）

**当前版本：1.19.2**

## v1.19.2 更新说明

> 本版为修复版：给全球指数国内源链路补上最后一层新浪兜底，并修复用户反馈的行拖拽落点偏移、新增条目位置异常、天气卡量能因子缺失三个问题。

### 全球指数新浪备份源

- 部分企业网同时阻断东方财富与 Yahoo，海外指数在 1.19.1 口径下只能整表隐藏；本版新增新浪 `b_` 批量行情作为第三层兜底，与既有新浪批量同一请求完成，不增加请求数
- 覆盖 16 个指数：日经 225、韩国 KOSPI、印度 SENSEX / NIFTY、英国富时、德国 DAX、法国 CAC40、瑞士、荷兰、西班牙、加拿大、新加坡、泰国、越南、南非 TOP40 等（用户企业网实测 + 补测确认）；东财 / Yahoo 取不到值时自动并入，统一标注延迟
- 顺带清理：移除历史遗留死键（`^N225` 旧新浪映射实测返回空，由 `b_NKY` 接管）；「选择显示指数」弹窗的网络标注同步补上新浪候选源

### 行拖拽排序修复

- 根因：向下拖动时落点比目标位置偏一格——插入点索引包含被拖行自身，而面板契约为先删后插，向下拖需要 -1；修复后拖到哪落到哪，原地释放判为无操作
- 拖拽插入指示线跟随主题默认色，多数主题下近乎不可见；现拖拽期间临时切换为高亮选中蓝，拖拽结束还原
- 股票 / 基金 / 期货 / 加密 / 全球五个表格共用同一处理器，一次修复全部受益（落点映射 112 例自测全过）

### 新增条目位置修复

- 排序序号此前按「当前行数」计算：删除若干行留下排序空洞后，新增的股票 / 基金等会插到列表中间；改为取现存最大序号 +1，新增条目永远排在末尾

### 市场天气量能环比兜底

- 根因：部分网络对东财分钟线域名（`push2his` 域名族）TLS 握手即掐（同时刻东财实时域 / 腾讯 / 新浪正常，属域名可达性问题而非东财停供），收盘后拿不到前一交易日全天成交额，天气卡「量能环比」因子缺失
- 新增本地成交额历史：交易日取到新浪两市成交额定型值后按日期持久化（保留 15 个交易日），东财取不到且处于全天口径时段时，按本地历史数据日前最近交易日全天额回退
- 护栏：本地历史间隔超过 12 天（超出春节 / 国庆最大合法间隔）视为空洞，宁可不显示也不出错；盘中累计口径不记录、不回退，维持「半天对全天宁可不显示」的既有约束

## v1.19.1 更新说明

> 本版包含一个新功能（隐秘模式）与一组用户反馈驱动的修复：1.18.3 起部分用户 IDE CPU 占用偏高，定位到插件后全面排查了轮询、监听、渲染与 JCEF 资源四类环节；同时继续补齐 1.19.0 全球指数国内源的遗留项，并把意见反馈通道改造为大陆网络可达。

### 隐秘模式（防窥屏）

- 开启后所有中文标的名称转为拼音展示：全拼档「贵州茅台 → GuiZhouMaoTai」，首字母档「贵州茅台 → GZMT」，旁人扫一眼看不出在看什么行情
- 涨跌颜色同步抹平为灰色（红涨绿跌是行情界面的最强视觉信号，一并隐藏）
- 工具窗口标题栏 👁 按钮一键循环切换：关闭 → 全拼 → 首字母；设置页「行情显示」内三态单选 + 「界面文字同步转拼音」开关可把标签页 / 表头 / 按钮等界面文案一并拼音化
- 只改展示层：搜索、分组、导入导出、AI 分析上下文、通知数据均用真名，关掉即完全还原；行情数值、K 线图不受影响

### CPU 占用高修复（API 日志面板）

- 根因：API 日志面板只要工具窗口存在，就会在**每一次行情 HTTP 请求**后于 EDT 全量重建列表——即使日志标签页没有打开；且每条日志的详情区（多组滚动区 / 文本域 / JSON 格式化）在构造时就全部建好，折叠状态也照样创建
- 修复：日志标签页不可见时完全不渲染（切回时一次补画）；可见时合并节流（重建封顶约 2 次/秒）；详情区与 JSON 美化延迟到首次展开才构建，折叠行只画头部一行

### 资源滞留修复（反复打开工具窗口）

- 根因：各标签页面板在应用级状态服务里注册的监听器从不摘除，轮询定时器不停止，内嵌 JCEF 图表浏览器创建后不释放——工具窗口每重开一次就净增一批僵尸监听器、定时器与图表实例，CPU 与内存随重开次数累积
- 修复：接入 IDE 生命周期，工具窗口销毁时统一摘除全部监听器、停止定时器、释放 JCEF 图表资源

### 状态栏后台轮询休市降频

- 纯 A 股持仓在休市静默时段（工作日 9:10–11:35 / 13:00–15:05 之外及周末），IDE 状态栏持仓服务的后台轮询从刷新间隔（默认 5 秒）降为 10 分钟一次；开盘时段与含港股 / 美股持仓的混合组合行为不变

### 全球指数源继续补齐

- **VIX** 新增 CBOE 官方行情（约 15 分钟延迟）与分时源：原腾讯 VIX 源数据已冻结，Yahoo 大陆不可达，此前该指数在大陆只能隐藏
- **欧洲STOXX50** 改用东财「欧洲斯托克50」代码，替代被阻断的 Yahoo
- **纳指100 图表数值修正**：东财 `100.NDX` 实为纳斯达克综合指数，纳指100 应取 `100.NDX100`——此前图表显示的是综合指数数值；反过来 `100.NDX` 正好补上纳指综合的图表兜底（腾讯美指分时休市时只回 1 个点）
- **东财 IPv4 不通自动回退 IPv6**：部分网络对东财 IPv4 握手后重置而 IPv6 正常，失败后自动解析 IPv6 地址直连（SNI 与证书仍按域名校验），这些网络下东财行情与图表恢复可用
- **可用性判定统一**：源可达 ≠ 该指数有数据——最近一轮行情取不到值的指数在「选择显示指数」弹窗中同样标注不可用，与面板自动隐藏口径一致，消除「设置里说可用、面板一直是 0.00」的矛盾

### 意见反馈通道大陆可达

- 反馈后端此前直连 Supabase，`*.supabase.co` 在大陆被 SNI 定向拦截，大陆用户反馈石沉大海；现改为**自有域名中转优先 + 直连兜底**，两者按序自动尝试

## 构建步骤

### 前置要求
- JDK 17+
- Gradle 8.8（或通过 wrapper 自动下载）

### 初始化 Gradle Wrapper（首次）
```bash
cd stocklite-plugin
gradle wrapper --gradle-version 8.8
```
> 如果没有全局 Gradle，可从 [gradle.org](https://gradle.org/install/) 安装，或用 IntelliJ IDEA 打开项目后让 IDE 自动处理。

### 在 IDE 沙箱中运行（开发调试）
```bash
./gradlew runIde
```
> 这会启动一个独立的 IntelliJ IDEA 沙箱实例，插件已加载。

### 打包为可安装 ZIP
```bash
./gradlew buildPlugin
```
输出路径：`build/distributions/stocklite-plugin-1.19.2.zip`

> **注意：** `buildSearchableOptions` 已禁用（防止沙箱 JVM 崩溃，exit code 3）。
> 签名默认关闭，仅在 `SIGN_PLUGIN=true` 时启用，本地构建无需证书文件。

### 签名并发布（仅上架 Marketplace 时）
```bash
set SIGN_PLUGIN=true   # Windows
./gradlew signPlugin publishPlugin
```

### 安装到 IDE
1. 打开 JetBrains IDE
2. Settings → Plugins → ⚙️ → Install Plugin from Disk
3. 选择上面生成的 ZIP 文件
4. 重启 IDE
5. 在右侧工具栏（或 View → Tool Windows → StockLite）打开面板

## 构建配置说明

`build.gradle.kts` 中有两项关键配置，解决常见构建问题：

```kotlin
// 禁用 buildSearchableOptions —— 该任务会启动沙箱 IDE 扫描设置项，
// 在部分环境下因内存/网络问题导致 JVM 崩溃（exit code 3）。
// 该任务仅影响"设置搜索"功能，禁用后不影响插件核心功能。
buildSearchableOptions {
    enabled = false
}

// 签名仅在 SIGN_PLUGIN=true 时启用，避免本地构建触发 downloadZipSigner 下载。
val signingEnabled = System.getenv("SIGN_PLUGIN") == "true"
signPlugin {
    enabled = signingEnabled
    // certificateChain / privateKey 仅在 signingEnabled 时配置
}
```

## 数据存储

数据保存在 IDE 配置目录下的 `stocklite.xml`：
- Windows: `%APPDATA%\JetBrains\<IDE>\options\stocklite.xml`
- macOS: `~/Library/Application Support/JetBrains/<IDE>/options/stocklite.xml`
- Linux: `~/.config/JetBrains/<IDE>/options/stocklite.xml`
