StockLite — 把股票行情和持仓账本装进 JetBrains IDE：写代码的同时看行情、记账、画K线、问 AI，全程不用离开编辑器。

A 股（含北交所）· 港股 · 美股 · 加密货币 · 基金 · 国内/国际期货 · 全球 19 大指数，一块原生面板全部搞定。纯 Kotlin/Swing 实现——没有 Electron、没有额外进程；免费、无广告、无需注册账号。

🏆 它和"行情插件"有什么不同

  • 不止看价格，还能记账 —— 交易记录（买入 / 卖出 / 清仓）、已实现盈亏、按历史仓位逐笔回放的盈亏走势曲线。多数插件只是报价器，StockLite 是一套持仓系统。
  • IDE 插件里独有的 AI —— 右键任意标的即可呼出 DeepSeek 深度分析：多轮对话、联网搜索，内置宏观 / 技术 / 基本面 / 量化 / 风控五种专家角色（需自备 API Key）。盘后多空信号自动记录、次日自动结算对错，信号芯片上直接显示历史准确率。
  • 盯盘细节拉满 —— 到价提醒、财报日期临近提醒、两市成交额放量/缩量同期对比、大盘涨跌家数与主力资金、股指期货多空动向、美股盘前盘后涨跌。
  • 为程序员准备 —— 每个 HTTP 请求可视化、一键复制 cURL；JSON 导入导出；多个 IDE 窗口数据实时同步；中英双语、红涨绿跌方案可切换。

📈 行情与持仓

  • 股票：沪深北 A 股 / 港股 / 美股实时行情；填写成本价与数量即可自动计算市值、浮动盈亏、累计收益率；支持自定义分组。批量导入：粘贴一段自选股文本（名称、6 位代码、sh/sz/bj/hk 前缀、.SZ/.SS 后缀、美股代码任意混排），自动解析校验、选择分组，重复自动合并、无效行沉底标注原因。
  • 基金：天天基金实时估值与官方净值双列显示，净值发布后自动切换；QDII 智能识别；右键可查看季度持仓明细，并附带持仓股的实时涨跌。
  • 期货：股指期货、商品期货与国际期货同板显示，秒级刷新。
  • 加密货币：BTC / ETH 等 2000+ USDT 计价交易对实时行情，7×24 小时交易，展示 24 小时滚动涨跌与 24h 高低价。Bitget → Gate.io → Binance 镜像三源自动降级，无需注册；面板顶部常驻连通状态指示，当前网络无法直连交易所接口时明确提示（可经 IDE HTTP 代理解决），其它标签页不受影响；安装后内置主流币，开箱即看。
  • 全球指数：沪深创 / 科创50、恒指 / 恒生科技、标普 / 道指 / 纳指 / 纳指100 / VIX、德法英日韩台印等 19 个指数；交易所节假日自动识别休市，延迟数据带来源标注。
  • 美股板块看板：30+ 行业与主题 ETF（AI、半导体、机器人、新能源、黄金、生物医药……）按板块网格排布；收盘 / 实时双视图，悬浮同时显示盘前、盘中、盘后三段行情。
  • 新股：新股申购日历 + 次新股表现一屏展示；今日申购自动气泡提醒；发行价对比行业市盈率；右键一键加自选并跳转东方财富。

📊 图表

  • 点击任意行的涨跌幅列，面板底部内嵌 TradingView 开源 lightweight-charts：日内 / 日K / 周K / 月K 真实蜡烛图，MA5 / MA10 / MA20 均线与成交量柱可开关，A 股日线前复权消除除权跳空。
  • 盈亏走势图：单只股票或全部持仓的每日浮动盈亏曲线，逐笔回放交易记录还原历史仓位，口径与持仓表完全一致。
  • 添加股票对话框内嵌行情卡片与K线图，下单前先看走势。

🌡️ A 股大盘概览（全球指数页底部）

  • 涨跌家数（含北交所）、涨跌停统计、两市成交额（悬浮对比上一交易日同一时刻，标注放量/缩量）、大小盘代表指数、领涨领跌板块、主力资金净流入。
  • 股指期货多空摘要：中金所四大品种（IH/IF/IC/IM）全部合约的中信期货及前二十席位当日净增减仓。
  • 盘后多空信号：综合 A50 / 纳指期货、期指持仓、资金面与大盘广度生成 -100 ~ +100 评分，每个因子悬浮可看判断理由。

🔔 提醒与日常细节

  • 行情来自新浪 / 腾讯 / 东方财富 / 天天基金 / Yahoo Finance / Bitget / Gate.io 等公开接口；A 股与港股为实时，美股等海外行情约有 15 分钟延迟（面板内已标注）。
