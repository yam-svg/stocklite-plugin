StockLite — 把股票行情和持仓账本装进 JetBrains IDE：写代码的同时看行情、记账、画K线、问 AI，全程不用离开编辑器。

A 股（含北交所）· 港股 · 美股 · 加密货币 · 基金 · 国内/国际期货 · 全球 19 大指数，一块原生面板全部搞定。纯 Kotlin/Swing 实现——没有 Electron、没有额外进程；免费、无广告、无需注册账号。

🏆 它和"行情插件"有什么不同

  • 不止看价格，还能记账 —— 交易记录（买入 / 卖出 / 清仓）、已实现盈亏、按历史仓位逐笔回放的盈亏走势曲线与按月盈亏热力日历。多数插件只是报价器，StockLite 是一套持仓系统。
  • IDE 插件里独有的 AI —— 右键任意标的即可呼出 DeepSeek 深度分析：多轮对话、联网搜索，内置宏观 / 技术 / 基本面 / 量化 / 风控五种专家角色（需自备 API Key）。每日盘前自动生成开盘跳空研判，开盘跳空与全天方向双账本收盘后自动结算，研判芯片直接显示历史命中率。
  • 盯盘细节拉满 —— 到价提醒、财报日期临近提醒、两市成交额放量/缩量同期对比、大盘涨跌家数与主力资金、股指期货多空动向、美股盘前盘后涨跌、A 股早盘集合竞价撮合价、涨跌停封单手数与封单锐减提醒。
  • 为程序员准备 —— 每个 HTTP 请求可视化、一键复制 cURL；JSON 导入导出；多个 IDE 窗口数据实时同步；中英双语、红涨绿跌方案可切换。

📈 行情与持仓

  • 股票：沪深北 A 股 / 港股 / 美股实时行情；填写成本价与数量即可自动计算市值、今日盈亏、浮动盈亏、累计收益率，数值列可在设置中按需增减；支持自定义分组。批量导入：粘贴一段自选股文本（名称、6 位代码、sh/sz/bj/hk 前缀、.SZ/.SS 后缀、美股代码任意混排），自动解析校验、选择分组，重复自动合并、无效行沉底标注原因。交易日早盘 9:15–9:30 自动显示集合竞价虚拟撮合价（与涨跌幅同行小字标注「竞价」），9:25 定格开盘价，开盘无缝切回连续行情。涨停 / 跌停股的涨跌幅旁显示封单手数，封板扎实与否一目了然。
  • 基金：官方净值与涨跌幅展示，东方财富官方数据源，净值日期一目了然；填写份额自动计算市值、今日盈亏与累计盈亏；右键可查看季度持仓明细，并附带持仓股的实时涨跌。
  • 期货：股指期货、商品期货与国际期货同板显示，秒级刷新；安装后内置纳斯达克100 与布伦特原油两大常用外盘合约，开箱即看。
  • 加密货币：BTC / ETH 等 2000+ USDT 计价交易对实时行情，7×24 小时交易，展示 24 小时滚动涨跌与 24h 高低价。Bitget → Gate.io → Binance 镜像三源自动降级，无需注册；面板顶部常驻连通状态指示，当前网络无法直连交易所接口时明确提示（可经 IDE HTTP 代理解决），其它标签页不受影响；安装后内置主流币，开箱即看。
  • 全球指数：沪深创 / 科创50、恒指 / 恒生科技、标普 / 道指 / 纳指 / 纳指100 / VIX、德法英日韩台印等 19 个指数；交易所节假日自动识别休市，延迟数据带来源标注。
  • 美股板块看板：30+ 行业与主题 ETF（AI、半导体、机器人、新能源、黄金、生物医药……）按板块网格排布；收盘 / 实时双视图，表格随交易时段动态展示盘前 / 盘后延伸行情，美股休市自动标注，非交易时段智能降频。
  • A 股板块：行业 / 概念 / 地域板块全市场涨跌榜，含换手率与主力资金净流入；领涨股可点开分时/K线；名称筛选、任意列排序，右键直达东方财富板块页。
  • 新股：新股申购日历 + 次新股表现一屏展示；今日申购自动气泡提醒；发行价对比行业市盈率；右键一键加自选并跳转东方财富。

📊 图表

  • 点击任意行的涨跌幅列，面板底部内嵌 TradingView 开源 lightweight-charts：日内 / 日K / 周K / 月K 真实蜡烛图，MA5 / MA10 / MA20 均线与成交量柱可开关，A 股日线前复权消除除权跳空。
  • 盈亏走势图与盈亏日历：单只股票或全部持仓的每日浮动盈亏曲线，逐笔回放交易记录还原历史仓位，口径与持仓表完全一致；同一弹窗内提供盈亏日历——按月热图呈现每日盈亏，格子颜色深浅随当日盈亏金额、涨跌配色跟随全局方案，右上角统计当月盈利 / 亏损天数，点任意一天展开当日各股盈亏明细。
  • 添加股票对话框内嵌行情卡片与K线图，下单前先看走势。

🌡️ A 股大盘概览（全球指数页底部）

  • 涨跌家数（含北交所）、涨跌停统计、两市成交额（悬浮对比上一交易日同一时刻，标注放量/缩量）、大小盘代表指数、领涨领跌板块、主力资金净流入。
  • 股指期货多空摘要：中金所四大品种（IH/IF/IC/IM）全部合约的中信期货及前二十席位当日净增减仓。
  • 盘前研判：交易日 8:40 起自动生成当日开盘研判——初版综合 A50、纳指隔夜、离岸人民币汇率与前一交易日定型数据，9:15 后并入韩国、日本早盘走势刷新为终版；给出高开 / 平开 / 低开隐含跳空与全天倾向，每个因子悬浮可看判断依据，芯片直接显示历史命中率。
  • 市场天气：每日收盘后按涨跌家数、涨停生态（连板梯队 / 炸板封板率）与量能环比输出 -100 ~ +100 情绪分与冰点 / 冷清 / 正常 / 热烈 / 过热五档，每日 A 股情绪温度计。

🔔 提醒与日常细节

  • 到价提醒（IDE 气泡通知）、封单锐减提醒（涨停封单快速减少提示警惕开板、跌停提示或现翘板机会，含大单抽单断崖识别）、财报临近圆点标记（≤7 天红色 / ≤30 天橙色）、快速筛选、三态排序、列宽记忆、各面板刷新频率独立配置、面板隐藏时自动暂停刷新。设置页开关按「行情面板 / 提醒通知 / 行情显示」分组，内置意见反馈入口直达开发者——匿名提交无需登录，「我的反馈」面板可随时查看提交历史与开发者回复、支持删除；封单锐减提醒可限定只盯持仓股票。除股票外的标签页均可在设置中单独开关，安装默认仅显示股票 / 基金 / 期货 / 全球四页，其余按需开启。工具窗口标题栏 ? 按钮内置新手指引，隐藏功能一键直达。

📌 三个必试操作
